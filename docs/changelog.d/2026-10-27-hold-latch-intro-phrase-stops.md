## 2026-10-27 - An order after an introductory phrase latches the hold

- From the Codex GitHub App review of PR #1152: "stop" followed by an -ing verb is skipped as description only when it comes right after a modal ("the hook should pause retrying") or later in a clause containing "make" ("make the gate stop refusing"). "At this point stop pushing" and "After this run stop pushing" latch again, and no longer clear an existing hold.
