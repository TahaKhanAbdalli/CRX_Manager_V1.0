## 2026-10-27 - A task-phrased stop latches the hold

- From the second Codex GitHub App review of PR #1152: "to stop the …" is skipped as description only in a clause that names a settings place (setting, config, env) or assigns a value with "=" and uses a setting verb such as set, change or disable (narrowed after the Sol review; a flag, option or variable alone no longer qualifies), like Mason's "set X=0 in my user settings to stop the per-commit security reviews". "Your next task is to stop the deploy", "Be certain to stop the deploy" and "Use the kill switch to stop the deploy" latch, and no longer clear an existing hold.
